
# CFC历史 | Page 1

> 前计算机团队时期

## 一、VM team/NVMT team时期  

### 1. 建立  

2022年1月27日，vmware15.5（后文称vm）与Win13Pro、Win81Pro组成VM team，任vm为团队领导人，该团队主要研究计算机软件为主。  

2022年1月末~2月初，团队以扩充队员为首要任务，同时完成团队的第一个项目"Windows 8 2022春节限定版"，此版封装系统以更改系统为春节主题为主，并且对原版系统进行了小幅优化。  

2月，vm团队取得了一系列成就：成员人数大大增长，拥有了官方网站，剪辑了第一个宣传片，拥有了第一个团队视频开头，完成了大量的PPT系统。（这些资料由当时的《VM团队2月月总结》PPT提供，现在可以在ColorFulCraft群文件中找到）

2月下旬，VM团队开发了一个电脑工具合集软件--VM Yauld Tools（代号“vmware真好”），此软件使用易语言开发。当时及其保密，甚至vm专门在其他社交平台建立一个新群聊来讨论它的开发。不过好景不长，项目仅仅启动了几天，就因技术问题而遭到放弃。

### 2. VM大提议  

2022年3月初，RealVM710（后文简称"710"）加入了VM team。他首先了解到团队的现状，总结了团队的大部分缺点，并向团队提出改正建议。领导人看后及其欣慰，提议成员要按照710的建议来规范行为。

这个事件使710迅速跻身于vm团队高层之列，成为团队的第二号人物。此后他开始参与团队的人事管理和项目开发工作。同时也为团队4月末的转型埋下伏笔。

### 3. 兴盛时期

在vm大提议之后，vm团队启动了一个封装系统项目——Windows VM OS。共拥有"10.1"、"10.1se"、"10.5"、"10.5 sp1"、"11"、"X" 6个版本号，其中VM 11和VM X 未开发完成。

然而在4月末，vm团队经历了一次转型，团队的工作重心被转移到软件开发上来。从4月末到5月中旬，VM团队成员参加项目的人数增至历史最大值，成员热情高涨，故此时间段为VM团队/NVMT（计算机团队）的鼎盛时期。

5月，成员Win81pro的3R60项目正式启动，当时开发的软件为3R60工具箱，定位和先前开发的VM Yauld Tools相似。此时VM团队还有一个软件开发项目--VM小工具，使用易语言开发，原计划被捆绑到3R60工具箱，包含的具体工具有时钟、计算器、浏览器和边栏（目前边栏和时钟已经丢失，现存的浏览器、计算器和它的源码被存储在ColorFulCraft群文件中）。

但3R60工具箱在VM团队/NVMT时期并未开发完成，后来NVMT并入WYS团队时该项目被交给子团队3r60工作室来完成开发，该项目最终完成。VM小工具的命运更悲惨，在团队并入WYS时该项目被砍。

### 4. 衰落  

2022年，由于新冠疫情得到控制，多地复工复学，团队成员不得不重新投入现实中学习和工作等原因，团队高层已无力管理团队，项目参与积极度锐减，此时团队进入了“假死”状态。多个项目烂尾，并且成员间出现了矛盾，团队已开始走下坡路。

随后，VM团队更名为NVMT，原意是“The New VM Team”（全新的VM团队）。具体的更名时间已经丢失，但目前据考证，更名时间大概率在2022年6月。

然而这段衰落的时期并非一事无成，在2022.7.22，NVMT team开启了一个MC服务器项目，它经过发展演变成为了现在的ColorFulCraft（这个就是后话了）。

### 5. 历史转折——7·31事件  

2022年7月下旬，团队成员710和领导人因项目开发问题发生争执，7月31日，710突然私下与几位团队主干成员交涉，劝导他们脱离团队，并让他们了解到团队的腐败。710的计划如期执行，失去了核心力量的团队迅速土崩瓦解，最后团队领导人宣布此团队并入WYS Team，NVMT team时期结束。  

并入WYS后的NVMT原计算机团队并没有开展过项目，虽然团队在名义上延续至今，但实际仍然处于“假死”状态。

7·31事件后，MC服务器项目被独立出来。vm也放弃了计算机科技研究，转战Minecraft服务器区。
